# Acceptance checklist

## Truth and structure

- All five real projects remain discoverable and have honest link states.
- OneBox - DNE describes the AI and automation internship with AWS, Java, Python, FastAPI, REST APIs, MySQL, PostgreSQL, maintenance, and bug fixing.
- PT, EN, and ES render meaningful content without placeholders.
- Curricula, contact channels, education, certifications, and language levels remain reachable.
- There is one `h1`; section headings form a logical hierarchy.

## Visual DNA

- Ink/paper/signal dominates; yellow occupies a controlled accent share.
- No aquatic remnants, dominant blue, purple glow, or generic AI gradient.
- Project compositions vary; they are not a repeated product-card grid.
- At most one or two strong decorative artifacts compete in a viewport.
- Type has clear display, reading, and mono roles.
- Bounding boxes indicate selection instead of becoming card borders.
- System-inspired surfaces do not pretend to be controls.

## Interaction and motion

- Controls respond in roughly 120-300 ms without layout jumps.
- Reveals never hide content when JavaScript or motion is unavailable.
- Scroll-linked motion uses transforms and stays out of the reading column.
- No infinite decorative WebGL render loop.
- Lenis and Three.js are dynamically gated and fully cleaned up.
- `prefers-reduced-motion: reduce` removes scrub, parallax, smooth scroll, and 3D.

## Mobile and performance

- Test 320, 360, 375, 390, 430, 768, 1024, 1440, and 1920 CSS-pixel widths.
- No horizontal overflow or clipped primary text.
- Touch targets are at least 44x44 CSS pixels.
- Mobile network entries contain no Three.js, desktop scene, frame sequence, or Lenis chunk.
- Local project videos mount only after explicit interaction.
- Production build records gzip sizes and identifies dynamic desktop-only chunks.

## Accessibility and production

- Skip link, landmarks, hash navigation, visible focus, keyboard menu, and modal focus return work.
- Decorative SVG/canvas is hidden from assistive technology.
- Text contrast meets WCAG AA; information does not depend on color alone.
- Lint, typecheck, unit tests, build, and end-to-end smoke tests pass without severe console errors.
- Metadata, canonical, favicon, robots, sitemap, manifest, and SPA fallback are valid.

## Scorecard

Score 0-10 with evidence:

- hierarchy;
- typography;
- palette;
- composition;
- clarity;
- originality;
- consistency;
- responsive behavior;
- mobile craft;
- accessibility;
- microinteractions;
- motion design;
- performance;
- personality;
- absence of generic AI UI.
